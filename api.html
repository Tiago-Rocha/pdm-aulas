API Tempo Açores

Uma API REST mantida pelo docente que envolve os dados abertos do IPMA, acrescenta autenticação por grupo, favoritos e telemetria, e serve de base ao projeto.

Em preparação A API entra em produção antes da aula 11. Esta página passará a mostrar a documentação OpenAPI interativa (Swagger UI), o endereço base, e como obter o token do teu grupo.

O que vai ter

Regras de uso

  • Cada grupo tem um client-id. Não o partilhes com outros grupos; os pedidos ficam registados por grupo.
  • Envia sempre os headers X-Platform (android, ios ou web) e X-App-Version.
  • Há limite de pedidos por minuto. Faz cache do lado da app: previsões não mudam a cada segundo.
  • O docente pode ligar o modo caos para o teu grupo: latência, respostas 429 e 500 aleatórias. A tua app deve continuar utilizável.
