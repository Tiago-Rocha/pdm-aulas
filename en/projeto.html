Tempo Açores

A weather app for the Azores, built on the course API, which in turn wraps IPMA's open data: 5-day forecast by location, weather warnings, earthquakes, synced favourites, map and notifications.

Open proposal The project app connects to a public API. This is the main proposal, on the IPMA API; another open API can be considered until the kickoff. The full brief, with minimum requirements, extras, sprint calendar and criteria, is published before lesson 15 (21/10).

Why this app

Because it has everything a real mobile app has: lists and details, data that changes, a network that fails, data worth keeping for when there is no network, location, notifications, and an API with authentication. And because the data is from here: the islands, the locations and the warnings are those of the Azores.

What the app does (minimum)

  • List of islands and locations, with search.
  • 5-day forecast for a location, with icons and minimum and maximum temperatures.
  • Active weather warnings for the Azores.
  • Favourites stored on the backend, tied to the group, synced across devices.
  • Works without a network using the last data fetched, and shows when the data is old.
  • Loading, error and empty states handled on every screen.

Extras that earn credit

  • Map with the locations and the current weather.
  • Local notification when a warning comes in for a favourite location.
  • Deep link that opens the app directly on a location.
  • Recent earthquakes in the region.
  • Light and dark theme, Portuguese and English.
  • Widget tests and CI running in the repository.

How you work

  1. Groups of 2 to 3. Formed in lesson 15. Each group gets a client-id for the course API and a repository through GitHub Classroom.
  2. Three sprints of about two weeks, with a review in class at the end of each one (02/11, 18/11, 02/12).
  3. Everything by pull request. Each feature is a PR reviewed by a colleague from the group before it goes into main.
  4. Distribution to testers from lesson 27 (20/11): the app installed on someone else's phone through Firebase App Distribution or TestFlight.
  5. Freeze on 09/12 and defences on 14 and 16/12, with a demo on the phone and questions to each member.

The course API

You will not call IPMA directly. The course API normalises the data, requires authentication with your group's token, stores the favourites, and from time to time is switched into chaos mode by the teacher (latency, 429 and 500 errors) so you can see whether your app copes. The documentation is at API from lesson 12.
