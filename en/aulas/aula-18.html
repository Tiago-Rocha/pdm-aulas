Today's goal: one PR from start to finish

  1. Branch: from an up-to-date main, a branch named after the track.
  2. Work: small commits, each with a sentence saying what changed.
  3. PR: push the branch and, on GitHub, Compare & pull request. Pick a teammate under Reviewers.
  4. Review: the teammate opens Files changed, comments on what they do not understand and, when it is fine, Approve.
  5. Merge: Merge pull request and Delete branch. Everyone pulls main.
Done Each group leaves with one PR reviewed and merged into main. Small and finished beats big and open.
This is what is assessed under process: branches, PRs reviewed by someone else, commits with messages that say what changed. If a group's track is big, split it into two PRs: the first can be just the theme or just the router with empty screens.

  • The first block before you start; the second every time a part works; the third after the merge, on every computer in the group.
  • They work the same in PowerShell and in the Mac terminal. The branch is named after your track: conta, navegacao or design-system.
Classic mistake: working on main without noticing. If it happens before the commit, git checkout -b conta takes the changes to the new branch. Another: push asks for a login; on Windows it opens the browser, on the Mac it may ask for a token (gh auth login solves it).

Track 1: the account

PieceWhere it comes from
Sign-up, login, logout, saved sessionpdm-aula-17, branch passo-2: copy it
Deleting the accountDELETE /v1/me, with the person's token
Changing the namePUT /v1/me with {"name": "..."}
  • The put() in the passo-2 ApiClient takes no body: you need one that does, like post().
  • Each new request is a method in AuthRepository and another in SessionNotifier; the screen only talks to the notifier.
  • Deleting the account asks for confirmation in a dialog, and then the app goes back to the login.
In the app Sign up, change the name, log out, log in again. Delete the account and try to log in with it: it must fail.
In pdm-aula-17: git stash -u and git checkout passo-2. Packages: flutter pub add http provider shared_preferences flutter_secure_storage. The package is tempo_acores on both sides. To delete: in the notifier, first the API, then session = null, _store.clear() and notifyListeners(). I tested DELETE /v1/me on the API: 204, and then login gives 401.
