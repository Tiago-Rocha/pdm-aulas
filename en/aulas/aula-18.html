Delete account 1 of 3: the data

  /// The account and everything in it disappear. There is no way back.
  Future<void> deleteAccount() async {
    await _api.delete('/v1/me'); // goes with the user's token
    _api.userToken = null;
  }
  • DELETE /v1/me goes with the person's token: the API knows who to delete without anything else.
  • The API deletes the account, the favourites and the sessions. The response is 204, with no body.
If they ask why no id is sent: /me is always whoever holds the token. Nobody can delete someone else's account.

Delete account 2 of 3: the state

  Future<void> deleteAccount() async {
    await _auth.deleteAccount(); // if it fails, the user stays logged in
    session = null;
    await _store.clear();
    notifyListeners(); // back to the login screen
  }
  • First the API, then the phone. If the request fails, the person stays logged in and can try again.
  • _store.clear() removes the ticket from secure storage: when the app opens, there is no session to restore.
Difference from logout: logout clears the phone first and the API is just a notice, because logging out has to work offline. Deleting the account offline cannot pretend it worked.

Security check: 5 minutes, on the group repository

git log -S "the-group-clientSecret" --oneline
git grep -n "http://"
git grep -n "uses-permission" -- android
  1. The first command must show nothing. If it shows a commit, the secret was published: ask for a new one in the credentials issue.
  2. The second one neither: everything on https://.
  3. The third must show INTERNET in android/app/src/main/AndroidManifest.xml. If it only shows up in debug and profile, release is missing it.
Do Run the three commands. If INTERNET is missing, add it in a PR, right after <manifest ...>: <uses-permission android:name="android.permission.INTERNET"/>
The commands are git commands and work in PowerShell. The secret goes in quotes, without writing it anywhere else. The project template only has INTERNET in the debug and profile manifests, so every group will need the line.
