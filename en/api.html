API Tempo Açores

A REST API run by the teacher: the islands and trails of the Azores, the real IPMA forecast, and a class feed of reports with text and a photo. It is the basis of mini-project 2.

Base URLhttps://api-pdm.sublimecipher.com
Interactive docshttps://api-pdm.sublimecipher.com/docs (Swagger: try every request in the browser)
OpenAPI specificationhttps://api-pdm.sublimecipher.com/openapi.json
FormatJSON in UTF-8; ISO 8601 dates; numbers as numbers
AuthenticationJWT: Authorization: Bearer <token> on every request except the token one

Getting started

  1. Your clientId and clientSecret are in an issue in your pdm-miniprojeto repository. They are yours only.
  2. Open the interactive docs. On POST /v1/auth/token, click Try it out, fill in the request and click Execute.
  3. Copy the accessToken, click Authorize at the top of the page and paste it. From then on every request carries the token.
  4. Try GET /v1/islands/sao-miguel/forecast: it is today's forecast, from IPMA.

Authentication

You exchange the clientId and clientSecret for a token, and send the token on every request. The token lasts 1 hour; when the API answers 401, ask for another.

POST /v1/auth/token
Content-Type: application/json

{
  "clientId": "pdm-ab12cd",
  "clientSecret": "your-secret"
}
{
  "accessToken": "eyJ0eXAiOiJKV1QiLCJhbGciOiJIUzI1NiJ9...",
  "tokenType": "Bearer",
  "expiresIn": 3600
}
GET /v1/islands
Authorization: Bearer eyJ0eXAiOiJKV1QiLCJhbGciOiJIUzI1NiJ9...
Security The token is a JWT: three base64 parts separated by dots, signed by the API. Anyone can read what is inside (paste it into jwt.io), but nobody can change it without the server's key. That is why it holds no secrets, only who you are and when it expires. The clientSecret, on the other hand, must not go into the code you commit: keep it outside git, for example with --dart-define.

Forecast

{
  "islandId": "sao-miguel",
  "islandName": "São Miguel",
  "location": "Ponta Delgada",
  "source": "IPMA",
  "updatedAt": "2026-10-13T09:31:02",
  "days": [
    {
      "date": "2026-10-13",
      "weatherType": {
        "id": 2,
        "description": "Céu pouco nublado",
        "category": "partlyCloudy"
      },
      "tMin": 17.6,
      "tMax": 23.6,
      "rainChance": 0,
      "wind": {
        "direction": "SE",
        "class": 2,
        "description": "Moderado"
      }
    },
    "..."
  ]
}
  • weatherType.category is one of the values of the class WeatherType enum: sunny, partlyCloudy, cloudy, rain or storm. The description is the IPMA text, in Portuguese.
  • rainChance goes from 0 to 100. IPMA does not give the wind speed in km/h, only the class: 1 weak, 2 moderate, 3 strong, 4 very strong.
  • The API asks IPMA at most every 30 minutes. If IPMA fails, it returns the last forecast it has; if it has none, it answers 502.

  "text": "Vento de sudoeste com rajadas até 90 km/h.",
  "startTime": "2026-10-26T06:00:00",
  "endTime": "2026-10-26T18:00:00"
}
  • Only yellow, orange and red warnings come back, most serious first. An empty list is the normal case: it means there are no warnings, and the app has to say so.
  • IPMA issues warnings per island group: AOR Eastern Group, ACE Central Group and AOC Western Group. islandIds says which islands each warning applies to; ?islandId=pico returns only the ones for Pico's area.
  • type is one of wind, rain, seaState, thunderstorm, fog, snow, hot or cold. The text may be empty. The labels come in Portuguese, as IPMA writes them.

Favourites

Favourites live in the account, not on the phone: two phones with the same clientId see the same ones. Adding and removing are idempotent: repeating the request always gives 204, so the app can safely try again.

More IPMA data

  • /v1/islands/{id}/sea: wave height and period, total sea height and water temperature for today and the next two days. IPMA only has three points in the Azores (Ponta Delgada, Horta and Santa Cruz das Flores); location says which one serves the island.
  • /v1/islands/{id}/observations: the IPMA stations on the island, each with its latest reading (temperature, humidity, wind, pressure, rain). Times are in UTC. Each station measures what it can: anything missing comes as null.
  • /v1/earthquakes: earthquakes in the last 30 days in the region, newest first, with the magnitude, depth, nearest island and, if it was felt, the intensity and where.

All the fields, with examples, are in the interactive documentation.

Reports

A report is a text, and optionally a photo, about the weather on an island. The feed belongs to the whole class: everyone sees everyone's reports, with the author's name, and each person only changes and deletes their own. The mine field says whether the report is yours.

  • POST answers 201 with the created report; PUT answers 200 with the changed report; DELETE answers 204, with no body.
  • The text has 1 to 500 characters. The photo is up to 8 MB; the API scales it to 1280 px on the longer side and stores it as JPEG.
  • Changing or deleting a report that is not yours gives 403.

Errors

When something goes wrong, the HTTP code says what kind of error it is and the body explains it (in Portuguese):

{
  "error": {
    "code": "not_found",
    "message": "Não há nenhuma ilha com o id \"atlantida\"."
  }
}
CodeWhenWhat the app should do
400Invalid request: missing field, empty or long text, photo that is not an imageShow the message to the user
401No token, invalid or expired tokenGet a new token and repeat the request
403The report is not yoursDo not show edit and delete on other people's reports (mine)
404The island, trail or report does not existShow "not found"
413Photo larger than 8 MBShrink the photo before sending
502IPMA did not answerShow an error with "Try again"

In Dart

With the http package (flutter pub add http). The examples were tested against the API.

import 'dart:convert';
import 'package:http/http.dart' as http;

const base = 'https://api-pdm.sublimecipher.com';

Future<String> getToken(String clientId, String clientSecret) async {
  final res = await http.post(
    Uri.parse('$base/v1/auth/token'),
    headers: {'Content-Type': 'application/json'},
    body: jsonEncode({'clientId': clientId, 'clientSecret': clientSecret}),
  );
  if (res.statusCode != 200) {
    throw Exception(jsonDecode(res.body)['error']['message']);
  }
  return jsonDecode(res.body)['accessToken'];
}
final res = await http.get(
  Uri.parse('$base/v1/islands/faial/forecast'),
  headers: {'Authorization': 'Bearer $token'},
);
final days = jsonDecode(res.body)['days'] as List<dynamic>;
final req = http.MultipartRequest('POST', Uri.parse('$base/v1/reports'))
  ..headers['Authorization'] = 'Bearer $token'
  ..fields['islandId'] = 'faial'
  ..fields['text'] = 'Céu limpo na Horta, mar calmo.'
  ..files.add(await http.MultipartFile.fromPath('photo', file.path));
final res = await http.Response.fromStream(await req.send());
// 201: jsonDecode(res.body) is the created report, with photoUrl
final res = await http.put(
  Uri.parse('$base/v1/reports/$id'),
  headers: {'Authorization': 'Bearer $token', 'Content-Type': 'application/json'},
  body: jsonEncode({'text': 'Afinal começou a chover às 17h.'}),
);

In Chrome, MultipartFile.fromPath does not work (there is no file system): use MultipartFile.fromBytes('photo', bytes, filename: 'photo.jpg') with the bytes the image picker returns.

Rules of use

  • Credentials are personal. Requests are logged under your name, and the reports you publish show it to the whole class.
  • Reports are public within the class: write as you would in a class group chat. The teacher can delete any report.
  • Cache on the app side: the forecast only changes every 30 minutes, you do not need to fetch it on every screen.
  • If you lose your clientSecret, ask the teacher for a new one.
