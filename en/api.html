Tempo Açores API

A REST API maintained by the teacher that wraps IPMA's open data, adds per-group authentication, favourites and telemetry, and is the base for the project.

Coming soon The API goes into production before lesson 12. This page will then show the interactive OpenAPI documentation (Swagger UI), the base address, and how to get your group's token.

What it will have

EndpointDescriptionAuth
POST /v1/auth/tokenExchanges the group's client-id and secret for a JWT token.no
GET /v1/locationsIslands and locations of the Azores with coordinates.yes
GET /v1/forecast/{locationId}5-day forecast, normalised (numbers as numbers, ISO dates, weather type resolved).yes
GET /v1/warningsActive weather warnings.yes
GET /v1/seismicRecent earthquakes in the Azores region.yes
GET/POST/DELETE /v1/me/favoritesThe group's favourites.yes
GET /icons/{weatherType}.svgWeather icons.no

Usage rules

  • Each group has a client-id. Do not share it with other groups; requests are logged per group.
  • Always send the headers X-Platform (android, ios or web) and X-App-Version.
  • There is a limit on requests per minute. Cache on the app side: forecasts do not change every second.
  • The teacher can switch on chaos mode for your group: latency, random 429 and 500 responses. Your app must stay usable.
