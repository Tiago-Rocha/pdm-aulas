Pergunta à turma Depois de apagar a conta, como é que a app volta sozinha ao ecrã de login?
Resposta. A SessionNotifier põe a session a null e chama notifyListeners(). O main está à escuta e, sem sessão, mostra o login. É o mesmo caminho do logout.

Apagar conta 1 de 3: os dados

  /// The account and everything in it disappear. There is no way back.
  Future<void> deleteAccount() async {
    await _api.delete('/v1/me'); // goes with the user's token
    _api.userToken = null;
  }
  • O DELETE /v1/me vai com o token da pessoa: a API sabe quem apagar sem mais nada.
  • A API apaga a conta, os favoritos e as sessões. A resposta é 204, sem corpo.
Se perguntarem porque não se manda o id: o /me é sempre quem tem o token. Ninguém consegue apagar a conta de outra pessoa.

Apagar conta 2 de 3: o estado

  Future<void> deleteAccount() async {
    await _auth.deleteAccount(); // if it fails, the user stays logged in
    session = null;
    await _store.clear();
    notifyListeners(); // back to the login screen
  }
  • Primeiro a API, depois o telemóvel. Se o pedido falhar, a pessoa continua com sessão e pode tentar outra vez.
  • O _store.clear() tira o talão do armazenamento seguro: ao abrir a app, já não há sessão para recuperar.
Diferença para o logout: no logout limpa-se primeiro o telemóvel e a API é só um aviso, porque sair tem de funcionar sem rede. Apagar a conta sem rede não pode fingir que funcionou.

Verificação de segurança: 5 minutos, no repositório do grupo

git log -S "o-clientSecret-do-grupo" --oneline
git grep -n "http://"
git grep -n "uses-permission" -- android
  1. O primeiro comando não pode mostrar nada. Se mostrar um commit, o segredo foi publicado: pede um novo no issue das credenciais.
  2. O segundo também não: tudo em https://.
  3. O terceiro tem de mostrar a INTERNET em android/app/src/main/AndroidManifest.xml. Se só aparecer em debug e profile, falta no release.
Faz Corre os três comandos. Se faltar a INTERNET, acrescenta num PR, logo a seguir a <manifest ...>: <uses-permission android:name="android.permission.INTERNET"/>
Os comandos são do git e funcionam no PowerShell. O segredo vai entre aspas, sem o escrever em mais lado nenhum. O template do projeto só tem a INTERNET nos manifestos de debug e profile, por isso todos os grupos vão precisar da linha.
